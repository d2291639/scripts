A collection of useful shell scripts to simplify common system tasks and development workflows. This repository is designed for developers, sysadmins, and anyone looking to automate repetitive tasks.

## Overview

This repository hosts a variety of scripts that help automate common tasks such as software installation, system setup, and container management. Each script is designed to be simple, modular, and reusable.  

All scripts are written in **Bash**, and most require `sudo` privileges to perform system-level operations.

---

## Available Scripts

| Script | Description |
|--------|-------------|
| `install-docker.sh` | Installs Docker and Docker Compose on Linux systems. |
| `install-gitlab.sh` | Installs GitLab and configures it. |

> ⚠️ **Note:** Some scripts may require `sudo` access depending on the tasks they perform.
